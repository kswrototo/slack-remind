# Slack 리마인드 설치 안내

Slack 메시지에 🔖 이모지를 달면 Mac 화면 오른쪽 위에 할 일로 뜨고, 정한 시간에 다시 알려 주는 앱이다. 아이폰 미리알림에도 같이 들어간다.

처음 한 번만 5분쯤 걸린다. macOS 14 이상에서 쓸 수 있다.

## 1. 앱 설치

1. [SlackRemind.zip 내려받기](https://github.com/kswrototo/slack-remind/releases/latest/download/SlackRemind.zip)를 눌러 받고, 더블클릭해 압축을 푼다.
2. 나온 `SlackRemind`를 응용 프로그램 폴더로 옮긴다.
3. 더블클릭해 연다. "확인되지 않은 개발자" 경고가 뜨면 완료(또는 확인)를 눌러 닫는다.
4. 시스템 설정 > 개인정보 보호 및 보안으로 가서 아래쪽의 "SlackRemind" 옆 **그래도 열기**를 누른다.
5. 다시 뜨는 창에서 열기를 누른다.

경고가 뜨는 이유: 사내에서 만든 앱이라 Apple의 공식 확인을 받지 않았다. 처음 한 번만 거치면 된다.

## 2. Slack 연결

화면 오른쪽 위 메뉴바의 체크리스트 아이콘을 누르면 연결 화면이 나온다.

1. **Slack 앱 만들기 열기**를 누른다. 브라우저가 열린다.
2. Workspace에서 Rototobebe를 고르고 Next를 누른다.
3. **Create and Install을 한 번만** 누른다. 여러 번 누르면 "너무 빨리 만들고 있다"는 오류가 난다.
4. 허용 화면이 나오면 허용을 누른다.
   - 허용 화면이 안 나오면: 왼쪽 메뉴 Install App → Install to Rototobebe → 허용.
5. 왼쪽 메뉴 OAuth & Permissions로 간다. User OAuth Token 옆 Copy를 누른다.
6. 앱의 연결 화면 칸에 붙여 넣고 **연결**을 누른다.
7. "미리알림에 접근" 창이 뜨면 허용을 누른다.

이 토큰은 본인 계정의 열쇠다. 다른 사람에게 보내거나 채팅에 붙이지 않는다.

## 3. 쓰는 법

| 하고 싶은 것 | 동작 |
|---|---|
| 등록 | Slack 메시지에 🔖(`:bookmark:`) 이모지를 단다. 5초 안에 설정 창이 뜬다 |
| 시간 정하기 | 뜬 창에서 1시간 뒤, 오후 4시, 내일 오전 9시 등을 누른다 |
| 시간 없이 저장 | 창 오른쪽 위 X |
| 목록 보기 | 메뉴바의 체크리스트 아이콘 |
| 완료 | 할 일 왼쪽 동그라미 |
| 원문 보기 | 화살표 아이콘 |
| 아이폰에서 보기 | 미리알림 앱의 "Slack 리마인드" 목록 |

## 알아 둘 것

- 앱이 읽는 것은 **내가 단 이모지가 붙은 메시지**와 보낸 사람 이름뿐이다. 다른 대화는 읽지 않는다.
- 메시지 내용은 본인 Mac과 본인 미리알림에만 저장된다. 회사 서버나 외부로 나가지 않는다.
- 설치하기 전에 달아 둔 🔖는 등록되지 않는다. 설치 후에 단 것부터 들어온다.
- "나중에 저장" 버튼(메시지에 마우스를 올리면 나오는 책갈피 아이콘)은 이모지가 아니라서 잡히지 않는다.
- Mac 로그인 때 자동으로 켜진다. 끄려면 시스템 설정 > 일반 > 로그인 항목에서 뺀다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 메뉴바에 아이콘이 없다 | 아이콘이 많으면 화면 가운데 카메라 부분 뒤로 가려진다. 안 쓰는 아이콘을 Command를 누른 채 끌어내 지운다 |
| 🔖를 달았는데 안 뜬다 | 메시지 아래에 🔖 1 표시가 붙었는지 본다. 같은 메시지에 다시 달 때는 뗀 뒤 5초 기다렸다 단다 |
| "연결 실패"가 나온다 | 토큰을 다시 복사한다. `xoxp-`로 시작해야 한다 |
| Slack에서 앱 만들기가 막힌다 | 워크스페이스 관리자에게 앱 설치 승인을 요청한다 |

그래도 안 되면 `~/Library/Logs/SlackRemind.log` 파일을 담당자에게 보낸다. 이 파일에는 메시지 내용과 토큰이 들어 있지 않다.

## 직접 빌드하기

개발자용. Xcode Command Line Tools가 있으면 `./build.sh` 한 번으로 `build/SlackRemind.app`과 배포용 zip이 만들어진다.
